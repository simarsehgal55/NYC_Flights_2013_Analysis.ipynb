# NYC Flights 2013 – Python Analysis

## Project Overview

This project analyses the NYC Flights 2013 dataset using Python to explore flight operations, delays, airline and airport performance, flight patterns, and relationships with weather conditions.

## Objectives

- Analyse flight delays and cancellation patterns
- Compare airline and airport performance
- Identify peak departure and arrival patterns
- Analyse flight distance and speed
- Explore relationships between weather conditions and flight delays

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Aggregation and statistical analysis
- Correlation analysis
- Data visualization

## Key Analysis Areas

- Airline performance
- Airport traffic and delays
- Departure-time patterns
- Flight distance and speed
- Delay patterns
- Weather and flight performance

## Project File

- `NYC_Flights_2013_Analysis.ipynb` – Complete Python analysis and visualizations
